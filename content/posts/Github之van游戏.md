# GitHub 项目推荐

- **[JHDev2006/Super-Mario-Bros.-Remastered-Public](https://github.com/JHDev2006/Super-Mario-Bros.-Remastered-Public)**  
  初代马里奥重制。

- **[JimVulkan/mali-panvk](https://github.com/JimVulkan/mali-panvk)**  
  天玑可用。替换原厂 Mali 驱动，修改 shader 编译路径，宝可梦剑盾可过开场动画。  

- **[Fy1ng/Fy1Sync](https://github.com/Fy1ng/Fy1Sync)**  
  给电竞观众用的桌面播放器: 一边放官方比赛画面, 一边放你喜欢的主播解说。
  
- **[UNIkeEN/SJMCL](https://github.com/UNIkeEN/SJMCL)**  
  跨平台 Minecraft 启动器，支持实例管理、CurseForge/Modrinth 资源下载与多账户登录

- **[PCL-Community/PCL-CE](https://github.com/PCL-Community/PCL-CE)**  
  基于 PCL 开源代码的社区版启动器，包含主线暂未制作的功能与改进

- **[fcambus/jsemu](https://github.com/fcambus/jsemu)**  
  JavaScript 模拟器合集，收录了大量用 JS 编写的各类平台模拟器

- **[YuHao2006/pvz_perf](https://github.com/YuHao2006/pvz_perf)**  
  基于 PvZ-Portable 优化的《植物大战僵尸》版本，重点优化 CPU 热路径、资源加载与图形提交，并支持多平台

- **[rafaelvcaetano/melonDS-android](https://github.com/rafaelvcaetano/melonDS-android)**  
  Kotlin的melonDS 的 Android 移植版

- **[melonDS-emu/melonDS](https://github.com/melonDS-emu/melonDS)**  
  NDS 模拟器，追求准确性与性能兼顾

- **[flyinghead/flycast](https://github.com/flyinghead/flycast)**  
  跨平台世嘉 Dreamcast / Naomi / Naomi 2 / Atomiswave 模拟器

- **[dolphin-emu/dolphin](https://github.com/dolphin-emu/dolphin)**  
  GameCube / Wii 模拟器，可在 PC 上以增强画质运行这两个平台的游戏

- **[FCL-Team/FoldCraftLauncher](https://github.com/FCL-Team/FoldCraftLauncher)**  
  Fold Craft Launcher，Android 上的 Minecraft：Java 版启动器

- **[moonlight-stream/moonlight-android](https://github.com/moonlight-stream/moonlight-android)**  
  Android 串流 支持stean sunshine

- **[stenzek/duckstation](https://github.com/stenzek/duckstation)**  
  PlayStation 1 模拟器，支持 x86-64/AArch32/AArch64/RV64

- **[endrift/gbajs](https://github.com/endrift/gbajs)**  
  浏览器里的 Game Boy Advance 模拟器，纯 JavaScript 实现

- **[DND5eChm/DND5e_chm](https://github.com/DND5eChm/DND5e_chm)**  
  《5E不全书》，DND 5e 已翻译资源的整合

- **[SSimco/Cemu](https://github.com/SSimco/Cemu)**  
  Cemu  Android 移植版

- **[cemu-project/Cemu](https://github.com/cemu-project/Cemu)**  
  Wii U 模拟器

- **[CrazyZhang666/EAappEmulater](https://github.com/CrazyZhang666/EAappEmulater)**  
  EA app 模拟器，用于绕过 EA Desktop 启动 EA 游戏

- **[Renegade0/InfinityUI](https://github.com/Renegade0/InfinityUI)**  
  IE:EE 游戏（博德之门/冰风谷增强版）的 UI 美化模组（Lua 编写）

- **[Pryaxis/TShock](https://github.com/Pryaxis/TShock)**  
  Terraria 服务端工具：提供服务端角色管理、反作弊与社区管理功能

- **[utkarshdalal/GameNative](https://github.com/utkarshdalal/GameNative)**  
  Android 原生玩 PC 游戏，集成 Steam / Epic / GOG / Amazon

- **[Droid-Deck/DroidDeck](https://github.com/Droid-Deck/DroidDeck)**  
  把 SteamOS 体验带到 Android

- **[MCCTeam/Minecraft-Console-Client](https://github.com/MCCTeam/Minecraft-Console-Client)**  
  轻量级 Minecraft 聊天控制台，支持自动化脚本
